**FRBench** provides a common interface to pretrained face-recognition models for privacy protection, adversarial robustness, and retrieval research. It is developed at the [HKU TASR Lab](https://github.com/HKU-TASR).

The library includes **45+ pretrained weights** across **25 backbones**, **9 loss functions**, and **3 training datasets**. Its differentiable pipeline supports gradient-based methods as well as embedding extraction and evaluation.

FRBench is a companion to [AFRBench / AFRLib]({{ '/portfolio/afrbench/' | relative_url }}): FRBench supplies face-recognition models, while AFRLib supplies privacy protection methods and AFRBench evaluates them in retrieval systems.

See the [GitHub repository](https://github.com/HKU-TASR/FRBench) for the current model list, installation instructions, and API examples.
