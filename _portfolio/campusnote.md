**CampusNote** is a university notice board and event-booking application developed by Group 8 for HKU COMP3278 in autumn 2026.

The application brings together posts and comments, direct messaging, moderation, and event booking. It uses Express and EJS for the web application and MySQL with handwritten SQL for data storage and queries.

This is a group project. See the [GitHub repository](https://github.com/Michael-wzl/CampusNote) for the source code, setup instructions, and contributor information.
